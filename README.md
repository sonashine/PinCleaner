# PinCleaner
Privacy Policy — Pin Cleaner

Last updated: August 12, 2026

This is a personal-use application built to identify duplicate Pins within a single Pinterest account.

What data this app accesses

This app uses the Pinterest API to read the authenticated user's own Pins and Boards, including Pin titles, image URLs, and links, for the sole purpose of detecting duplicate or near-duplicate Pins.

What this app does NOT do
It does not access, read, or process data belonging to any other Pinterest user.
It does not store Pin or Board data beyond the current session. Data is fetched fresh from the Pinterest API each time the app runs and is not retained, cached long-term, or written to any database.
It does not share, sell, or transmit any data obtained from the Pinterest API to any third party.
It does not automatically delete, modify, or take any action on Pins or Boards without the user explicitly reviewing and confirming each individual action.
It does not combine Pinterest account data with data from any other account or service.
Data retention

No Pinterest data is retained after a session ends. API access tokens are stored locally on the user's own device only and are never transmitted to a third-party server.
